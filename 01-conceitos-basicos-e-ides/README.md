# 📂 01: Lógica Básica de Programação

Este diretório concentra os primeiros passos no aprendizado de Python. O foco aqui foi compreender a sintaxe inicial da linguagem, a manipulação de variáveis, os tipos de dados primitivos e a execução de operações matemáticas fundamentais.

## 🛠️ Scripts

* **`01_conceitos.py`**: 
  * **Objetivo**: Introdução à sintaxe do Python.
  * **Conceitos**: Uso do comando `print()`, entendimento de tipos de dados primitivos (como Strings e Inteiros) e exibição de dados estruturados no terminal.
  
* **`02_operadores.py`**:
  * **Objetivo**: Prática com cálculos aritméticos e atribuição de valores.
  * **Conceitos**: Operadores matemáticos (+, -, *, /) e lógicos, criação e atualização de variáveis na memória do computador.

## 💻 Como Executar

Para testar os scripts deste módulo, abra o seu terminal dentro desta pasta e execute:

```bash
# Para testar os conceitos de sintaxe
python 01_conceitos.py

# Para testar os operadores matemáticos
python 02_operadores.py
```
