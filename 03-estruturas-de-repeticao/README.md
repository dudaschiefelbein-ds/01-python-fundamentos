Tabuadas em Python 🐍

Este repositório contém scripts simples em Python para praticar estruturas de repetição e lógica de programação através da criação de tabuadas.

📁 Arquivos do Projeto

01- for.py: Tabuada do 2 feita manualmente com vários comandos print().

02- for.py: Tabuada do 2 automatizada usando o laço for e range().

03-while.py: Tabuada interativa usando while para permitir que o usuário digite o número e decida quando encerrar o programa.

04-tabuada.py: Geração automática de todas as tabuadas (do 1 ao 10) usando laços for aninhados.

🚀 Como Executar

Para rodar qualquer um dos scripts, utilize o Python no terminal:

python "01- for.py"
python "02- for.py"
python "03-while.py"
python "04-tabuada.py"
