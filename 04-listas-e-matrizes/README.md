# 📁 Módulo 04 - Listas e Matrizes

Neste módulo, explorei detalhadamente as **Estruturas de Dados e Coleções** em Python. Os códigos cobrem desde a manipulação básica de sequências mutáveis até matrizes bidimensionais, coleções imutáveis e mapeamentos complexos usando dicionários.

### 🧠 Conceitos Praticados:
* **Listas (`[]`):** Estruturas ordenadas e maleáveis que aceitam valores duplicados.
* **Matrizes:** Listas multidimensionais organizadas em linhas e colunas (listas dentro de listas).
* **Conjuntos (`{}`):** Coleções que não aceitam valores duplicados e não possuem uma ordem fixa.
* **Tuplas (`()`):** Sequências totalmente imutáveis (trancadas) que preservam a ordem dos elementos.
* **Dicionários e Objetos:** Armazenamento de dados no formato de Chave-Valor para representar um elemento com múltiplos atributos.

---

### 💻 Arquivos Criados no Módulo:

#### 1. `listas_e_colecoes.py`
* **Descrição:** Explora o funcionamento de índices, medição e alteração dinâmica de listas.
* **Recursos Utilizados:** 
  * `len()`: Verifica a quantidade de itens presentes na lista.
  * `.append()`: Insere novos elementos no final da estrutura.
  * `.remove()` e `del`: Métodos para exclusão de dados por valor ou índice específico.
  * `sorted()`: Ordenação alfabética e numérica dos elementos.
  * `for`: Laço de repetição utilizado para automatizar a leitura e exibição de dados item por item de forma otimizada.

#### 2. `matrizes_multidimensionais.py`
* **Descrição:** Criação e mapeamento visual de uma estrutura bidimensional em tabelas.
* **Recursos Utilizados:** 
  * Indexação por colchetes múltiplos (`matriz[linha][coluna]`), onde o primeiro índice localiza a lista interna (linha) e o segundo localiza o elemento (coluna).

#### 3. `dicionarios_e_estruturas.py`
* **Descrição:** Implementação de conjuntos, tuplas, dicionários individuais e estruturas complexas combinadas.
* **Recursos Utilizados:** 
  * `set()`: Instanciação de conjuntos para barrar dados duplicados.
  * Declaração de Tuplas para dados estáticos.
  * **Lista de Dicionários:** Estrutura avançada reunindo cadastros onde cada posição da lista armazena um dicionário completo com chaves de `Nome`, `Telefone` e `Endereco`.
